# 🎙️ VK Voice Downloader (`gs_vk`)

> Расширение для браузеров на базе Chromium (**Manifest V3**), позволяющее скачивать голосовые сообщения из **ВКонтакте** (`vk.com` и `vk.ru`) в один клик — прямо из диалогов, пересланных сообщений, верхнего аудиоплеера шапки или списком через всплывающее окно.

---

## ✨ Основные возможности

- 📥 **Кнопка скачивания прямо в чате:**
  - Автоматически встраивает аккуратную иконку загрузки рядом с каждым голосовым сообщением в диалогах ВКонтакте.
  - Поддерживает вложенные и **пересланные голосовые сообщения**, а также мини-плеер в верхней шапке страницы.
- 🔍 **Умный перехват аудиопотоков:**
  - Перехватывает и нормализует прямые ссылки на аудиофайлы (`.ogg`, `userapi.com/s/v1/`, `psv*.vk`, `audiomsg`) через связку `injected.js`, `content.js` и фонового `service_worker` (`webRequest`).
  - Автоматически отсекает системные звуки уведомлений и звонков ВК (`msg.mp3`, `notification`, `incoming.mp3` и т.д.).
  - Сопоставляет перехваченные аудиопотоки с конкретными DOM-элементами голосовых сообщений по длительности и порядку воспроизведения.
- 📦 **Массовое скачивание через Popup (`v2.0`):**
  - Стильный тёмный интерфейс попапа со счётчиком найденных голосовых сообщений на открытой вкладке.
  - Кнопка **«Скачать все»** для пакетной загрузки всех обнаруженных ГС одним нажатием.
  - Индивидуальное скачивание выбранных записей из списка с отображением времени и статуса.

## 📁 Структура проекта

```text
gs_vk/
├── manifest.json       # Конфигурация расширения Chrome (Manifest V3)
├── background.js       # Service Worker: перехват сетевых запросов и управление загрузками
├── content.js          # Content Script: поиск ГС в DOM, вставка кнопок и связь с попапом
├── content.css         # Стили встроенных кнопок скачивания в интерфейсе ВК
├── injected.js         # Скрипт уровня страницы для перехвата Audio/Fetch/XHR плеер-событий
├── popup.html          # Разметка всплывающего окна расширения
├── popup.css           # Тёмная тема оформления попапа
├── popup.js            # Логика списка найденных ГС и пакетного скачивания
└── icons/              # Иконки расширения (16x16, 48x48, 128x128)
```

## 🚀 Установка (Режим разработчика)

1. Склонируйте репозиторий или скачайте архив с исходным кодом:
   ```bash
   git clone https://github.com/dvd-bolt/gs_vk.git
   ```
2. Откройте браузер (Chrome, Edge, Brave, Яндекс.Браузер) и перейдите на страницу расширений:
   ```text
   chrome://extensions/
   ```
3. Включите переключатель **«Режим разработчика»** (*Developer mode*) в правом верхнем углу.
4. Нажмите **«Загрузить распакованное расширение»** (*Load unpacked*) и выберите папку `gs_vk`.

---

## 📖 Как пользоваться

1. Откройте диалог с голосовыми сообщениями на [vk.com](https://vk.com) или [vk.ru](https://vk.ru).
2. Нажмите на кнопку **скачивания (⬇)** рядом с нужным голосовым сообщением (если ссылка ещё не подгружена ВК, нажмите *Play* на голосовом сообщении — расширение мгновенно перехватит аудиопоток и скачает файл).
3. Либо откройте иконку **VK Voice Downloader** на панели расширений браузера, чтобы увидеть список всех найденных голосовых на странице и нажать **«Скачать все»**.

---

## 🔒 Приватность и безопасность

- Расширение работает **полностью локально** в вашем браузере.
- Никакие сообщения, токены или аудиозаписи не передаются на сторонние серверы.
